## Claude Code News — 30.03.2026

Najważniejsze wiadomości ze świata AI z ostatnich 48 godzin.

### Wyciek danych ujawnia nowy model Claude Mythos

Anthropic potwierdził istnienie modelu Claude Mythos po wycieku danych. Firma określiła go jako „przełomowy skok" w możliwościach AI — model ma znacząco przewyższać obecne rozwiązania w zakresie rozumowania i programowania.

Źródło: [Fortune](https://fortune.com/2026/03/26/anthropic-says-testing-mythos-powerful-new-ai-model-after-data-leak-reveals-its-existence-step-change-in-capabilities/)

### Mythos a cyberbezpieczeństwo — ostrzeżenie Anthropic

W kolejnym komunikacie Anthropic ostrzegł urzędników rządowych, że Claude Mythos stanowi bezprecedensowe ryzyko w kontekście cyberbezpieczeństwa. To rzadki przypadek, gdy firma AI sama sygnalizuje potencjalne zagrożenia swojego produktu.

Źródło: [Fortune](https://fortune.com/2026/03/27/anthropic-leaked-ai-mythos-cybersecurity-risk/)

### Claude Code v1.0.x — szybszy start i lepsze zabezpieczenia

Nowa wersja Claude Code przynosi nowy nagłówek sesji API, szybszy start o 30ms oraz lepszą ochronę przed przypadkowym usuwaniem katalogów na Windows.

Źródło: [Anthropic Docs](https://docs.anthropic.com/en/release-notes/claude-code)

### Mythos przewyższa Opus 4.6 w programowaniu

Według doniesień SiliconANGLE, Claude Mythos z zaawansowanym rozumowaniem przewyższa obecny flagowy model Opus 4.6 w benchmarkach programistycznych. Premiera planowana w najbliższych tygodniach.

Źródło: [SiliconANGLE](https://siliconangle.com/2026/03/27/anthropic-launch-new-claude-mythos-model-advanced-reasoning-features/)

### Claude otrzymuje sterowanie komputerem w preview

Anthropic udostępnił w wersji preview funkcję pozwalającą Claude na bezpośrednie sterowanie komputerem — klikanie, wpisywanie tekstu i nawigację po interfejsie graficznym.
